The Brake · 3-Layer Safety

No Single Point of Failure

1
Coordinator System Prompt — Mandate Rules
7 escalation triggers encoded verbatim: security/finance → always escalate · VIP/executive → always escalate · confidence < 0.70 → low-confidence reason · impact > €5,000 → high-impact reason · injection detected → escalate · frozen account → escalate · category=other → escalate
2
Zod Decision Schema — Runtime Validation + Retry
superRefine checks cross-field invariants at parse time. auto-resolve only for identity. action=escalate requires escalation_required=true. confidence < 0.70 must include low-confidence reason. On failure: Zod error injected into next prompt → retry × 2.
3
PreToolUse Hook — Deterministic Code Gate
Runs before every write tool call. Blocks: frozen / disabled / under-investigation accounts · VIP and executive users · prompt injection score ≥ 0.8. Code-level — cannot be overridden by rephrasing the ticket or manipulating the conversation context.
