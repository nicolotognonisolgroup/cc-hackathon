Safety Design

Three Layers, No Gaps

1
Coordinator System Prompt — Mandate Rules
7 escalation triggers encoded in the prompt. Security/finance always escalate. VIP always escalate. Confidence < 0.70 → low-confidence reason.
2
Zod Decision Schema — Runtime Validation
superRefine checks cross-field constraints. auto-resolve only for identity. action=escalate requires escalation_required=true. Zod error → retry prompt (max 2).
3
PreToolUse Hook — Deterministic Code Gate
Runs before EVERY write tool. Blocks frozen/disabled/under-investigation accounts. Blocks VIP and executive users. Blocks injection score ≥ 0.8. Cannot be overridden by rephrasing.

Summary

What We Built

Agentic Core

Coordinator + 3 specialists via Claude Agent SDK. Task subagents with explicit context passing. No inherited state — everything is explicit.

Safety Architecture

3-layer defense: prompt rules + Zod runtime + PreToolUse hook. The hook is immune to prompt injection — it runs at the code level.

11 Custom Tools

Per-specialist tools via in-process MCP server. Descriptions state what each tool does NOT do. Errors are structured, never raw strings.

Eval-Driven

35-example eval harness with stratified and adversarial sets. Scorecard against 4 mandate thresholds. JSON output for CI integration.
